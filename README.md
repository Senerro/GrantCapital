# GrantCapital
Реализация тестового задания. 

Для запуска приложения необходимо:
1. Установить Docker
2. Запустить docker-compose из среды разработки или же через терминал, перейдя в дерикторию с файлом и прописать docker-compose ip -d
3. Установить плагины Lombock

В рамках выполняемой задачи был вынужден изменить таблицу Account, добавив ей поле initDeposit в рамках реализации Sheduler для корректного расчёта предельной суммы депозита
